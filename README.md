### 🌐 Социальная сеть
Приложение позволяет пользователям просматривать ленту публикаций, ставить лайки, делиться, редактировать и удалять собственные посты. Пользователь может авторизоваться или выйти из аккаунта, после чего данные автоматически обновляются с сервера. Реализована поддержка загрузки фото и видео, а также получение push-уведомлений о новых событиях через Firebase Cloud Messaging.

---

### :computer: Что сделано :

1. Функционал постов:
  - Загрузка постов с сервера с использованием Paging 3
  - Возможность лайкать/анлайкать, удалять, редактировать посты
  - Поддержка картинок (загрузка фото из камеры/галереи и отправка на сервер)
2. Авторизация:
  - Экран SignIn (вход с логином/паролем)
  - Состояние авторизации хранится через AppAuth с помощью SharedPreferences
  - Использование токена для запросов (интерцептор в OkHttp добавляет Authorization)
  - При logout токен удаляется, данные обновляются
3. Push-уведомления:
  - Интеграция с Firebase Cloud Messaging (FCM)
4. UI:
  - XML-вёрстка + ViewBinding
  - Использование Fragment’ов + Navigation Component для переходов
  - Экран ленты (FeedFragment), создания поста (NewPostFragment), авторизации (SignInFragment), просмотра фото (ImageFragment)
  - Обновление списка через SwipeRefreshLayout
5. Архитектура:
  - MVVM с ViewModel и LiveData/Flow
  - Hilt (Dagger Hilt) для внедрения зависимостей
  - Room для локального кэширования постов
  - Retrofit + OkHttp для сетевых запросов
  - Glide для загрузки изображений

### 	:floppy_disk: Как работает :
1. При запуске проверяется авторизация (есть ли токен)
2. Загружается лента постов с сервера (через PostPagingSource и Pager)
3. Пользователь может:
   - добавить пост (с фото/без фото)
   - лайкнуть/убрать лайк
   - поделиться постом
   - удалить или отредактировать свой пост
4. При login/logout данные пересоздаются (через flatMapLatest по AppAuth.state)
